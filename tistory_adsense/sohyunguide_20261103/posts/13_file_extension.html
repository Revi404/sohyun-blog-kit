세줄요약
  • 윈도우 11 파일 탐색기에서 보기 > 표시 > 파일 확장명을 누르면 .jpg, .pdf 같은 확장자가 보여요.
  • 같은 메뉴의 숨긴 항목을 누르면 숨김 파일과 폴더가 흐릿하게 나타나요.
  • 확장자가 보이면 이름만 그럴듯한 가짜 문서 파일을 구분하기 쉬워져 보안에도 도움이 돼요.
확인 환경 2026-11-03윈도우 11 홈·프로파일 탐색기

“견적서.pdf”라고 적힌 첨부파일을 받았는데 열었더니 이상한 프로그램이 실행됐다는 이야기, 들어 보셨나요? 😨 윈도우는 기본적으로 파일 확장명을 숨겨 두기 때문에, 실제로는 ‘견적서.pdf.exe’인 실행 파일이 ‘견적서.pdf’처럼 보일 수 있어요. 확장자를 항상 보이게 바꿔 두는 건 가장 쉬운 보안 습관이에요.

파일 확장명 보이게 하기

  1. Win + E로 파일 탐색기를 열어요.
  2. 위쪽 메뉴에서 보기를 눌러요.
  3. 맨 아래 표시에 마우스를 올려요.
  4. 파일 확장명을 눌러 체크 표시가 생기면 완료예요 ✅

이제 모든 폴더에서 ‘사진.jpg’, ‘계약서.hwp’처럼 점 뒤의 확장자까지 함께 보여요.

숨김 파일 보이게 하기

같은 보기 > 표시 메뉴에서 숨긴 항목을 누르면 숨김 처리된 파일과 폴더가 반투명하게 나타나요. 프로그램 설정 파일이 들어 있는 AppData 폴더처럼, 문제 해결 안내를 따라 하다 보면 숨김 폴더에 들어가야 할 때가 있어요.

숨김 파일은 대부분 윈도우나 프로그램이 일부러 숨겨 둔 거예요. 용도를 모르는 숨김 파일은 지우거나 옮기지 마세요. 볼 일이 끝나면 다시 숨겨 두는 게 실수를 줄이는 방법이에요.

자주 보는 확장자 정리

확장자종류주의
.jpg · .png · .heic사진·이미지.heic는 아이폰 사진 형식
.pdf · .hwp · .docx · .xlsx문서평소 업무 파일
.zip · .7z압축 파일압축을 풀고 안의 확장자 확인
.mp4 · .mov동영상.mov는 아이폰 영상 형식
.exe · .msi · .bat · .scr실행 파일메일·메신저로 받았다면 열기 전에 꼭 확인

특히 문서인 줄 알고 받은 파일이 .exe, .scr, .bat로 끝난다면 바로 열지 말고 보낸 사람에게 다시 확인하는 게 안전해요.

확장자를 바꿀 때 주의할 점

확장자가 보이면 파일 이름을 바꿀 때 확장자까지 같이 지워지거나 바뀔 수 있어요. 이름 바꾸기(F2)를 누르면 윈도우가 확장자 앞부분만 선택해 주니, 그 상태에서 이름만 입력하면 돼요. 확장자를 일부러 바꾸면 “파일을 사용할 수 없게 될 수 있습니다” 경고가 뜨는데, 확장자를 바꾼다고 파일 형식이 실제로 변환되는 건 아니에요. 예를 들어 .hwp를 .pdf로 이름만 바꾸면 열리지 않아요. 형식을 바꾸려면 해당 프로그램의 다른 이름으로 저장이나 PDF로 내보내기 기능을 써야 해요.

메일·메신저 첨부파일 안전하게 여는 습관

확장자를 보이게 했다면, 첨부파일을 열기 전에 다음 세 가지만 습관처럼 확인해 보세요 🛡️

첫째, 파일 이름 맨 끝의 확장자가 내용과 맞는지 봐요. ‘청구서’라면 .pdf나 .hwp가 자연스럽고, .exe나 .js라면 이상한 거예요. 둘째, ‘청구서.pdf .exe’처럼 이름 중간에 공백을 많이 넣어 진짜 확장자를 화면 밖으로 밀어내는 수법도 있어요. 파일 이름이 유난히 길다면 이름 바꾸기(F2)를 눌러 끝까지 확인해 보세요. 셋째, 압축 파일(.zip)로 온 첨부는 압축을 푼 뒤 안에 든 파일의 확장자를 다시 확인해야 해요.

조금이라도 의심스러우면 열지 말고 보낸 사람에게 전화나 다른 메신저로 직접 확인하는 게 가장 확실한 방법이에요.

자주 묻는 질문

폴더마다 다시 설정해야 하나요?

아니요. 파일 확장명과 숨긴 항목 표시는 모든 폴더에 한 번에 적용돼요.

바탕화면 파일에도 확장자가 보이나요?

네, 바탕화면도 하나의 폴더라 같은 설정이 적용돼요. 다만 바로 가기 아이콘은 확장자가 표시되지 않아요.
