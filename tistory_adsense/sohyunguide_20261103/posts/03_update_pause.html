세줄요약
  • 윈도우 11 업데이트는 설정 > Windows 업데이트 > 업데이트 일시 중지에서 1주 단위로 최대 5주까지 미룰 수 있어요.
  • 작업 중 갑자기 재시작되는 게 싫다면 사용 시간을 설정해 두면 그 시간대에는 자동으로 다시 시작하지 않아요.
  • 일시 중지 기간이 끝나면 밀린 업데이트를 먼저 설치해야 다시 중지할 수 있어요.
확인 환경 2026-11-02윈도우 11 홈·프로설정 앱

중요한 문서를 쓰고 있는데 “업데이트를 위해 다시 시작합니다”가 뜨면 정말 식은땀이 나죠 😰 업데이트를 영원히 막을 수는 없지만, 내가 원하는 때에 설치하도록 조절하는 건 충분히 가능해요. 설정 화면에서 할 수 있는 방법만 모았어요.

업데이트 일시 중지하기

  1. Win + I로 설정을 열어요.
  2. 왼쪽 맨 아래 Windows 업데이트를 눌러요.
  3. 업데이트 일시 중지 옆의 드롭다운에서 기간을 골라요. (1주~5주)
  4. 화면 위에 “업데이트가 ○월 ○일까지 일시 중지됨”이 보이면 완료예요 ✅
여행이나 마감처럼 PC를 꼭 써야 하는 기간에만 일시 중지하고, 끝나면 바로 업데이트 다시 시작을 눌러 밀린 업데이트를 받는 게 가장 안전해요.

자동 재시작을 피하는 ‘사용 시간’ 설정

일시 중지 말고도, 업데이트는 받되 작업 시간에는 재시작하지 않게 할 수 있어요.

  1. Windows 업데이트 > 고급 옵션으로 들어가요.
  2. 사용 시간을 ‘수동’으로 바꾸고 시작·종료 시간을 정해요. (최대 18시간)
  3. 예를 들어 오전 8시~오후 11시로 두면, 그 사이에는 자동 재시작이 일어나지 않아요.

같은 화면의 다시 시작하기 전에 알림 받기도 켜 두면, 재시작 15분 전에 알림이 와서 저장할 시간이 생겨요.

업데이트를 너무 오래 미루면 생기는 일

보안 업데이트에는 이미 알려진 해킹 경로를 막는 수정이 들어 있어요. 5주를 넘겨 계속 미루는 방법(서비스 끄기, 레지스트리 수정 등)은 보안상 추천하지 않아요.

또 일시 중지 기간이 끝나면 윈도우가 밀린 업데이트를 한꺼번에 설치하기 때문에, 오히려 재시작 시간이 길어질 수 있어요. 미뤘다면 여유 있는 저녁에 직접 설치해 두는 게 좋아요.

업데이트 기록 확인하고 문제 생긴 업데이트 지우기

업데이트 후에 프린터가 안 되거나 특정 프로그램이 이상해졌다면, 최근에 설치된 업데이트가 원인일 수 있어요. 이럴 땐 기록부터 확인해 보세요 🔍

  1. 설정 > Windows 업데이트 > 업데이트 기록으로 들어가요.
  2. 품질 업데이트 목록에서 날짜를 보고 문제가 시작된 날 설치된 항목(KB로 시작하는 번호)을 확인해요.
  3. 맨 아래 업데이트 제거를 누르고, 해당 KB 번호 옆의 제거를 선택해요.
  4. PC를 다시 시작한 뒤 증상이 사라졌는지 확인해요.

제거한 뒤에는 같은 업데이트가 바로 다시 설치되지 않도록 1주 정도 일시 중지를 걸어 두고, 수정판이 나오길 기다리는 게 좋아요. 모든 업데이트가 제거 목록에 나오는 건 아니고, 일부 보안 업데이트는 제거할 수 없어요.

선택적 업데이트는 꼭 설치해야 하나요?

Windows 업데이트 > 고급 옵션 > 선택적 업데이트에 들어가 보면 드라이버나 기능 미리보기가 따로 모여 있어요. 이 목록은 자동으로 설치되지 않는 항목이라, 지금 PC에 문제가 없다면 굳이 설치하지 않아도 괜찮아요. 반대로 프린터·그래픽·사운드처럼 특정 장치가 제대로 동작하지 않을 때는 이 목록에 해당 장치의 새 드라이버가 올라와 있는지 확인해 보세요. 문제 해결에 바로 도움이 되는 경우가 많아요.

또 같은 화면의 ‘최신 업데이트가 제공되는 즉시 받기’ 스위치는 새 기능을 빨리 받아 보는 옵션이에요. 안정성이 더 중요하다면 꺼 두는 쪽을 추천해요.

자주 묻는 질문

‘업데이트 일시 중지’ 버튼이 회색이에요

이미 최대 기간까지 중지했거나, 회사·학교 관리 PC라 관리자가 정책을 걸어 둔 경우예요. 개인 PC라면 밀린 업데이트를 먼저 설치하면 다시 선택할 수 있어요.

업데이트 중에 전원을 꺼도 되나요?

“전원을 끄지 마세요” 화면이 나올 때 강제로 끄면 부팅 오류가 생길 수 있어요. 노트북은 충전기를 꽂은 상태에서 끝날 때까지 기다려 주세요.
