확인 환경 2026-11-02윈도우 11 홈·프로설정 앱

C 드라이브 막대가 빨간색으로 바뀌면 PC가 느려지고 업데이트도 실패하기 쉬워요 😥 그렇다고 아무 폴더나 지우면 프로그램이 망가질 수 있죠. 윈도우 11에는 지워도 안전한 파일만 골라 주는 기능이 들어 있어서, 별도 프로그램 없이도 꽤 많은 공간을 확보할 수 있어요.

1단계. 어디에 용량이 쓰였는지 확인

  1. Win + I → 시스템 > 저장소로 들어가요.
  2. 잠시 기다리면 앱 및 기능 · 임시 파일 · 문서 · 사진 등 항목별 사용량이 나와요.
  3. 더 많은 범주 표시를 누르면 숨은 항목까지 볼 수 있어요.

대부분은 임시 파일과 앱이 상위권이에요. 사진·동영상이 많다면 외장 드라이브나 클라우드로 옮기는 것도 같이 고려해 보세요.

2단계. 정리 권장 사항으로 한 번에 지우기

  1. 같은 화면에서 정리 권장 사항을 눌러요.
  2. 임시 파일 · 크거나 사용하지 않는 파일 · 클라우드에 동기화된 파일 · 사용하지 않는 앱 탭이 나와요.
  3. 각 탭에서 지울 항목에 체크하고 정리를 눌러요 ✅
항목지워도 되나요?주의할 점
Windows 업데이트 정리대부분 안전설치가 끝난 업데이트 찌꺼기
임시 인터넷 파일·미리 보기안전다시 생성돼요

다운로드 항목은 기본으로 체크되지 않을 수도 있지만, 체크하면 다운로드 폴더 전체가 지워져요. 꼭 폴더를 먼저 열어 보고 선택하세요.

3단계. 저장소 센스로 자동 정리 켜기

  1. 시스템 > 저장소에서 저장소 센스 스위치를 켜요.
  2. 저장소 센스 글자를 눌러 세부 설정으로 들어가요.
  3. 실행 주기(매일·매주·매월·디스크 공간 부족 시), 휴지통 파일 보관 기간(1·14·30·60일)을 정해요.
처음에는 실행 주기: 매월 / 휴지통: 30일 / 다운로드: 사용 안 함 정도로 보수적으로 두는 걸 추천해요. 실수로 지운 파일을 되찾을 여유가 생겨요.

그래도 부족하다면

앱이 큰 비중을 차지한다면 설정 > 앱 > 설치된 앱에서 정렬을 크기로 바꿔 보세요. 오래 안 쓴 게임이나 프로그램이 위로 올라와요. 이름 옆 … 버튼에서 바로 제거할 수 있어요.

새 파일이 다른 드라이브에 저장되게 바꾸기

D 드라이브나 두 번째 SSD가 있다면, 앞으로 새로 저장되는 문서·사진·동영상이 처음부터 그쪽으로 가도록 바꿀 수 있어요. C 드라이브가 다시 차오르는 걸 막는 데 효과가 커요 💡

  1. 시스템 > 저장소 > 고급 저장소 설정을 펼쳐요.
  2. 새 콘텐츠가 저장되는 위치를 눌러요.
  3. 새 앱 · 새 문서 · 새 음악 · 새 사진 · 새 동영상 항목마다 저장할 드라이브를 골라 적용을 눌러요.

이 설정은 앞으로 새로 생기는 파일에만 적용돼요. 이미 C 드라이브에 있는 파일은 직접 옮겨야 해요. 문서 폴더 전체를 옮기고 싶다면 파일 탐색기에서 문서 폴더를 오른쪽 클릭 → 속성 > 위치 탭 → 이동으로 위치를 바꾸면 안의 파일까지 함께 옮겨져요.

여유 공간은 얼마나 남겨 두는 게 좋을까?

정확한 기준이 정해져 있는 건 아니지만, C 드라이브가 거의 가득 차면 윈도우 업데이트 파일을 내려받을 자리가 없어서 업데이트가 실패하거나, 임시 파일을 만들지 못해 프로그램이 느려질 수 있어요. 큰 기능 업데이트를 앞두고 있다면 미리 넉넉하게 비워 두는 게 마음 편해요. 저장소 화면 맨 위 막대가 파란색에서 빨간색으로 바뀌면 정리할 때가 됐다는 신호로 보면 돼요.

자주 묻는 질문

정리했는데 용량이 거의 그대로예요

사진·동영상·문서 같은 개인 파일은 윈도우가 지우지 않아요. 저장소 화면에서 문서·사진·동영상 항목이 크다면 직접 옮기거나 정리해야 해요.

‘WinSxS’ 폴더가 너무 커요. 지워도 되나요?

안 돼요. 윈도우 구성 요소가 들어 있는 폴더라 직접 지우면 시스템이 손상될 수 있어요. 정리 권장 사항의 ‘Windows 업데이트 정리’로 줄이는 게 안전해요.
