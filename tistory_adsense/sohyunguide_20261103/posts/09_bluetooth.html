세줄요약
  • 블루투스 기기가 안 잡히면 먼저 기기를 페어링 모드로 바꿨는지, 다른 기기(휴대폰)에 이미 연결돼 있지 않은지 확인해요.
  • 윈도우 쪽은 블루투스 끄고 켜기 → 장치 제거 후 다시 추가 → 문제 해결사 순서로 점검해요.
  • 블루투스 스위치 자체가 사라졌다면 장치 관리자에서 드라이버를 다시 설치해요.
확인 환경 2026-11-03윈도우 11 홈·프로무선 이어폰 · 마우스 · 키보드

어제까지 잘 되던 무선 이어폰이 오늘따라 PC에서 안 잡히면 회의 직전에 진땀이 나죠 🎧 블루투스 연결 문제는 원인이 기기 쪽인지 윈도우 쪽인지만 가려내도 절반은 해결돼요. 간단한 것부터 순서대로 따라 해 보세요.

1단계. 기기 쪽부터 확인

확인할 것이유
배터리 충분한지배터리가 적으면 페어링 신호가 약해져요
페어링 모드인지보통 버튼을 길게 눌러 불이 깜빡이는 상태
휴대폰에 연결돼 있지 않은지대부분 이어폰은 한 번에 한 기기에만 붙어요
PC와 거리처음 연결할 땐 1m 안쪽에서 시도
휴대폰과 PC를 번갈아 쓰는 이어폰이라면, 휴대폰의 블루투스를 잠깐 꺼 두고 PC에서 연결하면 훨씬 잘 잡혀요.

2단계. 윈도우 블루투스 다시 켜기

  1. 작업 표시줄 오른쪽 아래 와이파이·소리 아이콘 부분을 눌러 빠른 설정을 열어요.
  2. 블루투스 버튼을 눌러 껐다가 5초 뒤 다시 켜요.
  3. 그래도 안 되면 PC를 한 번 다시 시작해요.

3단계. 장치 제거 후 다시 연결

예전에 연결했던 기록이 꼬여 있으면 목록에 이름은 보이는데 연결만 실패해요. 이럴 땐 기록을 지우고 새로 연결하는 게 가장 확실해요.

  1. Win + I → 블루투스 및 장치 > 장치로 들어가요.
  2. 문제의 기기 옆 …을 눌러 장치 제거를 선택해요.
  3. 기기를 다시 페어링 모드로 만들어요.
  4. 장치 추가 > Bluetooth를 누르고 목록에 뜬 기기를 선택해요 ✅

4단계. 문제 해결사 실행

윈도우에는 블루투스 문제를 자동으로 점검하는 도구가 있어요. 설정 > 시스템 > 문제 해결 > 기타 문제 해결사에서 Bluetooth 옆 실행을 누르면, 서비스가 꺼져 있거나 설정이 잘못된 부분을 찾아 고쳐 줘요.

5단계. 블루투스 버튼이 아예 없을 때

빠른 설정과 설정 앱에서 블루투스 메뉴가 통째로 사라졌다면 드라이버 문제일 가능성이 높아요.

  1. 시작 버튼을 오른쪽 클릭해 장치 관리자를 열어요.
  2. Bluetooth 항목을 펼쳐 무선 어댑터(Intel, Realtek 등)를 찾아요.
  3. 오른쪽 클릭 → 디바이스 제거를 누른 뒤 PC를 다시 시작하면 윈도우가 드라이버를 다시 설치해요.
‘이 장치의 드라이버 소프트웨어를 삭제합니다’에는 체크하지 마세요. 체크하면 드라이버 파일까지 지워져 자동으로 다시 설치되지 않을 수 있어요. 노트북이라면 제조사 지원 프로그램에서 최신 드라이버를 받는 방법도 있어요.

빠른 연결(Swift Pair) 켜 두기

윈도우 11에는 지원하는 블루투스 기기를 페어링 모드로 두기만 하면 화면 오른쪽 아래에 “연결하시겠습니까?” 알림이 뜨는 기능이 있어요. 블루투스 및 장치 > 장치 화면 아래쪽의 빠른 연결을 사용하여 연결하는 알림 표시를 켜 두면, 설정 앱에 들어가지 않고 알림의 연결 버튼 한 번으로 끝나요. 모든 기기가 지원하는 건 아니지만, 최근에 나온 마우스·키보드·이어폰은 지원하는 경우가 많아요.

반대로 회의실이나 카페처럼 블루투스 기기가 많은 곳에서 알림이 계속 뜬다면 이 스위치를 꺼 두면 돼요.

자주 묻는 질문

이어폰이 연결됐는데 소리가 스피커로 나와요

블루투스 연결과 소리 출력 장치 선택은 별개예요. 작업 표시줄 스피커 아이콘을 누르고 볼륨 막대 옆 > 버튼에서 이어폰 이름을 출력 장치로 골라 주세요.

연결은 되는데 소리가 끊겨요

와이파이 공유기와 블루투스는 같은 2.4GHz 대역을 써서 서로 간섭할 수 있어요. 공유기에서 조금 떨어지거나, 와이파이를 5GHz로 바꾸면 좋아지는 경우가 많아요. USB 3.0 장치(외장 하드 등)가 블루투스 어댑터 가까이 꽂혀 있어도 간섭이 생길 수 있어요.

마우스가 잠깐 멈췄다 움직여요

절전 설정 때문에 블루투스 어댑터가 쉬었다 깨는 경우예요. 장치 관리자에서 블루투스 어댑터 속성의 전원 관리 탭에 있는 ‘전원을 절약하기 위해 컴퓨터가 이 장치를 끌 수 있음’을 해제해 보세요.
