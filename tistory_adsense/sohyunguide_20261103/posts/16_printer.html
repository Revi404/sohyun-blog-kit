세줄요약
  • 윈도우 11 프린터는 설정 > 블루투스 및 장치 > 프린터 및 스캐너 > 장치 추가로 연결해요.
  • 엉뚱한 프린터로 인쇄된다면 Windows에서 내 기본 프린터 관리를 끄고 기본 프린터를 직접 지정해요.
  • 인쇄가 멈춰 있으면 인쇄 대기열을 비우고 프린터 문제 해결사를 실행해요.
확인 환경 2026-11-03윈도우 11 홈·프로USB · 와이파이 프린터

급하게 서류를 뽑아야 하는데 인쇄 버튼을 눌러도 아무 반응이 없거나, 엉뚱하게 ‘PDF로 저장’ 창이 뜨면 당황스럽죠 🖨️ 윈도우 11 프린터 문제는 대부분 연결, 기본 프린터 지정, 막힌 인쇄 대기열 세 가지 중 하나예요. 순서대로 정리해 볼게요.

프린터 새로 연결하기

  1. 프린터 전원을 켜고, USB 프린터는 케이블을 PC에 꽂아요. 와이파이 프린터는 PC와 같은 공유기에 연결돼 있어야 해요.
  2. Win + I → 블루투스 및 장치 > 프린터 및 스캐너로 들어가요.
  3. 장치 추가를 누르고 잠시 기다려요.
  4. 목록에 프린터 이름이 뜨면 장치 추가를 눌러요 ✅

대부분의 프린터는 윈도우가 드라이버를 자동으로 찾아 설치해요. 스캔 기능까지 쓰려면 제조사에서 제공하는 전용 프로그램을 따로 설치해야 하는 경우도 있어요.

목록에 프린터가 안 나올 때

연결 방식확인할 것
USB케이블을 다른 USB 포트에 꽂아 보기, 허브 대신 PC에 직접 연결
와이파이프린터 화면에서 네트워크 연결 상태 확인, PC와 같은 공유기인지
공유기 교체 후프린터의 와이파이 설정을 새 공유기로 다시 잡아야 해요
오래된 모델장치 추가 화면의 수동으로 추가에서 IP 주소로 연결

와이파이 프린터의 IP 주소는 보통 프린터 자체 메뉴의 ‘네트워크 정보’나 ‘설정 보고서 인쇄’로 확인할 수 있어요.

기본 프린터 직접 지정하기

윈도우 11은 기본값으로 마지막에 사용한 프린터를 기본 프린터로 바꿔요. 그래서 한 번 PDF로 저장했더니 다음부터 계속 PDF 창이 뜨는 일이 생겨요.

  1. 프린터 및 스캐너 화면 아래쪽 Windows에서 내 기본 프린터 관리를 꺼요.
  2. 목록에서 실제로 쓰는 프린터를 눌러요.
  3. 기본값으로 설정을 누르면 프린터 이름 아래에 ‘기본값’이 표시돼요 ✅
‘Microsoft Print to PDF’는 실제 프린터가 아니라 문서를 PDF 파일로 저장해 주는 가상 프린터예요. 지우지 말고 기본값에서만 빼 두면 필요할 때 유용하게 쓸 수 있어요.

인쇄가 대기열에서 멈췄을 때

문서 하나가 오류로 걸려 있으면 뒤에 보낸 문서도 전부 멈춰요. 이럴 땐 대기열부터 비워야 해요.

  1. 프린터 및 스캐너에서 프린터를 누르고 인쇄 대기열 열기를 선택해요.
  2. 멈춘 문서를 오른쪽 클릭해 취소하거나, 위쪽 … → 모두 취소를 눌러요.
  3. 그래도 안 지워지면 PC와 프린터를 둘 다 껐다 켜요.
  4. 프린터 화면의 문제 해결사 실행도 같이 해 보세요.

인쇄 전에 미리 확인하면 종이를 아껴요

인쇄 창의 미리보기를 한 번만 확인해도 잘못 뽑아 버리는 종이를 크게 줄일 수 있어요. 특히 웹페이지를 인쇄하면 광고나 메뉴까지 같이 나와서 몇 장씩 늘어나는 경우가 많아요. 이럴 땐 인쇄 창에서 페이지 범위를 필요한 쪽만 지정하거나, 브라우저 인쇄 설정의 머리글·바닥글 옵션을 끄면 깔끔해져요. 여러 쪽짜리 자료는 한 장에 2쪽 모아 찍기를 쓰면 종이가 절반으로 줄어요.

인쇄 품질이 이상할 때

글자가 흐리거나 줄이 생긴다면 PC가 아니라 프린터 쪽 문제일 가능성이 높아요. 프린터 메뉴의 헤드 청소·노즐 점검을 실행하고, 잉크·토너 잔량을 확인해 보세요. 잉크젯 프린터를 오래 안 쓰면 잉크가 굳어 품질이 떨어지기 쉬워서, 일주일에 한 번 정도 짧은 문서를 인쇄해 주는 것도 관리 요령이에요.

자주 묻는 질문

프린터가 ‘오프라인’으로 표시돼요

프린터 전원이 꺼졌거나 네트워크 연결이 끊긴 상태예요. 프린터를 다시 켜고, 와이파이 프린터라면 공유기 연결을 확인한 뒤 PC를 다시 시작해 보세요. 그래도 그대로면 프린터를 목록에서 제거하고 다시 추가하는 게 가장 확실해요.

양면 인쇄 메뉴가 안 보여요

인쇄 창의 기타 설정이나 프린터 속성 안에 들어 있는 경우가 많아요. 프린터가 자동 양면 인쇄를 지원하지 않는 모델이면 ‘수동 양면’만 선택할 수 있어요.
