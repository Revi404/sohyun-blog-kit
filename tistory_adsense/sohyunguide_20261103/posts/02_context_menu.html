지금 바로 예전 메뉴 여는 3가지 방법

방법하는 법특징
메뉴에서 누르기오른쪽 클릭 → 맨 아래 더 많은 옵션 표시가장 기본, 클릭 2번

가끔만 쓰신다면 레지스트리를 건드리지 말고 Shift + 오른쪽 클릭만 손에 익혀도 충분해요.

예전 메뉴로 아예 고정하는 방법

압축 프로그램, 이미지 편집 프로그램처럼 오른쪽 클릭 메뉴를 자주 쓰신다면 기본 메뉴 자체를 예전 형태로 바꿔 두는 게 편해요. 레지스트리에 값 하나를 추가하는 방식이에요.

  1. 시작 버튼을 누르고 cmd를 입력해 명령 프롬프트를 열어요. (관리자 권한은 필요 없어요)
  2. 아래 명령을 그대로 붙여 넣고 Enter를 눌러요.
    reg add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve
  3. “작업을 완료했습니다”가 나오면 PC를 다시 시작하거나 로그아웃 후 다시 로그인해요.
  4. 이제 오른쪽 클릭하면 처음부터 예전 메뉴가 열려요 ✅
레지스트리는 윈도우 설정이 저장된 곳이라, 명령을 한 글자라도 다르게 입력하지 않도록 꼭 복사해서 붙여 넣으세요. 위 명령은 현재 사용자(HKCU) 설정만 바꾸고 시스템 전체에는 영향을 주지 않아요.

다시 윈도우 11 메뉴로 되돌리기

  1. 명령 프롬프트를 열어요.
  2. 아래 명령을 붙여 넣고 Enter를 눌러요.
    reg delete "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}" /f
  3. PC를 다시 시작하면 원래 간단 메뉴로 돌아와요.

간단 메뉴에 있는 아이콘 뜻

윈도우 11 간단 메뉴 맨 위(또는 아래)에 글자 없이 아이콘만 있는 줄이 있어요. 처음엔 뭐가 뭔지 헷갈리는데, 순서대로 잘라내기 · 복사 · 이름 바꾸기 · 공유 · 삭제예요. 마우스를 올려 두면 이름이 나와요.

레지스트리를 바꾸기 전에 백업해 두기

위 명령은 값 하나만 추가하는 간단한 작업이지만, 레지스트리를 처음 건드린다면 백업을 한 번 해 두면 마음이 편해요 🙂

  1. Win + R을 누르고 regedit를 입력해 레지스트리 편집기를 열어요.
  2. 왼쪽에서 컴퓨터를 선택한 뒤 파일 > 내보내기를 눌러요.
  3. 내보내기 범위를 모두로 두고 바탕화면 등에 저장해요.

문제가 생기면 저장한 .reg 파일을 더블 클릭해 원래 값을 다시 들일 수 있어요. 다만 전체 백업은 파일이 크고 시간이 걸리니, 이번처럼 한 항목만 바꿀 때는 아래 ‘되돌리기’ 명령을 메모장에 같이 저장해 두는 정도로도 충분해요.

간단 메뉴가 더 편한 경우도 있어요

윈도우 11 간단 메뉴는 터치스크린 노트북이나 태블릿 모드에서 누르기 쉽게 만든 디자인이에요. 메뉴가 짧아서 원하는 항목을 빨리 찾을 수 있고, 프로그램이 많이 깔려 있어도 메뉴가 길게 늘어지지 않아요. 압축·편집 프로그램을 자주 쓰지 않는다면 기본 메뉴를 그대로 두고 Shift + 오른쪽 클릭만 기억해 두는 쪽을 추천해요.

큰 기능 업데이트 뒤에는 설정이 초기화되는 경우가 있어요. 같은 명령을 한 번 더 입력하면 다시 적용돼요.
