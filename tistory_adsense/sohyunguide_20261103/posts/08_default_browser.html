세줄요약
  • 윈도우 11 기본 브라우저는 설정 > 앱 > 기본 앱에서 크롬·웨일 등을 고른 뒤 기본값으로 설정을 누르면 바뀌어요.
  • 그래도 일부 링크가 엣지로 열린다면, 같은 화면에서 .htm·.html·HTTP·HTTPS 연결을 확인해요.
  • 위젯·시작 메뉴 검색 결과 링크는 기본 브라우저 설정과 상관없이 엣지로 열릴 수 있어요.
확인 환경 2026-11-03윈도우 11 홈·프로설정 앱

크롬이나 웨일을 설치하고 “기본 브라우저로 설정할까요?”에 ‘예’를 눌렀는데, 메일 속 링크를 누르면 여전히 엣지가 열린다… 이런 경험 꽤 흔해요 🤔 윈도우 11은 브라우저 하나를 통째로 지정하는 대신 파일 형식과 링크 종류별로 기본 앱을 정하는 방식이라 그래요. 한 번만 제대로 바꿔 두면 다시 신경 쓸 일이 없어요.

기본 브라우저 한 번에 바꾸기

  1. 먼저 원하는 브라우저(크롬, 웨일, 파이어폭스 등)를 설치해요.
  2. Win + I → 앱 > 기본 앱으로 들어가요.
  3. 앱 목록에서 원하는 브라우저 이름을 눌러요.
  4. 맨 위 기본값으로 설정 버튼을 누르면 웹 관련 형식이 한꺼번에 바뀌어요 ✅
‘기본값으로 설정’ 버튼이 안 보이면 윈도우 업데이트가 밀린 경우가 많아요. 설정 > Windows 업데이트에서 최신 업데이트를 먼저 설치해 주세요.

그래도 엣지로 열릴 때 확인할 항목

‘기본값으로 설정’을 눌렀는데도 일부 링크가 엣지로 열린다면, 같은 화면 아래쪽 목록에서 아래 항목이 내 브라우저로 되어 있는지 하나씩 확인해 보세요.

항목무엇을 열 때
HTTP · HTTPS메일·메신저·문서 속 인터넷 주소
.htm · .htmlPC에 저장된 웹페이지 파일
.pdfPDF 문서 (브라우저로 열고 싶을 때만)
.svg · .webp일부 이미지 파일

항목을 누르면 앱 고르기 창이 뜨고, 원하는 브라우저를 선택하면 바로 바뀌어요. 이 창에서 엣지를 계속 추천하는 안내가 나와도 다른 앱 선택을 누르면 돼요.

설정과 상관없이 엣지로 열리는 곳

위치동작
작업 표시줄 위젯(날씨·뉴스)엣지로 열리는 경우가 많아요
시작 메뉴 검색의 웹 결과엣지·빙 검색으로 열려요
윈도우 도움말 링크엣지로 열릴 수 있어요

이건 기본 앱 설정의 문제가 아니라 윈도우 기능 쪽 동작이에요. 위젯을 잘 안 쓴다면 설정 > 개인 설정 > 작업 표시줄에서 위젯을 꺼 두는 게 가장 간단해요.

PDF는 어떤 프로그램으로 열까?

기본 브라우저를 바꿀 때 PDF까지 같이 브라우저로 바뀌는 경우가 있어요. 문서를 보기만 한다면 브라우저로도 충분하지만, 서명·메모·양식 입력이 필요하다면 전용 PDF 뷰어를 따로 지정하는 게 편해요. 기본 앱 맨 위 검색창에 .pdf를 입력하면 바로 바꿀 수 있어요.

브라우저를 바꿀 때 같이 옮기면 좋은 것

기본 브라우저만 바꾸고 나면 즐겨찾기와 저장된 비밀번호가 없어서 불편할 수 있어요. 대부분의 브라우저는 처음 실행할 때나 설정 메뉴의 가져오기 기능으로 다른 브라우저의 데이터를 옮길 수 있어요.

옮길 항목가져오기로 가능한지메모
즐겨찾기(북마크)대부분 가능폴더 구조도 같이 옮겨져요
저장된 비밀번호대부분 가능옮긴 뒤 원래 브라우저 쪽은 정리 권장
방문 기록브라우저마다 다름꼭 필요하지 않으면 생략
확장 프로그램직접 다시 설치같은 이름으로 검색해 설치

크롬에서는 설정 > 나와 Google > 북마크 및 설정 가져오기, 웨일에서는 설정 > 기본 > 북마크 및 설정 가져오기처럼 비슷한 이름의 메뉴를 찾으면 돼요. 메뉴 위치는 브라우저 업데이트에 따라 조금씩 달라질 수 있어요.

자주 묻는 질문

메일 프로그램 속 링크만 엣지로 열려요

윈도우 기본 메일 앱이나 일부 업무용 프로그램은 자체 설정에서 링크를 여는 브라우저를 따로 정해요. 해당 프로그램의 설정 메뉴에서 ‘링크 열기’ 또는 ‘브라우저’ 항목을 찾아 시스템 기본값으로 바꿔 보세요.

엣지를 아예 지워도 되나요?

윈도우 11에서 엣지는 시스템 구성 요소라 일반적인 방법으로는 제거할 수 없어요. 무리하게 지우면 도움말·위젯 등 일부 기능이 제대로 열리지 않을 수 있으니, 기본 앱만 바꿔 두는 걸 추천해요.

업데이트 후 기본 브라우저가 엣지로 돌아갔어요

큰 업데이트 뒤에 설정이 초기화되는 경우가 드물게 있어요. 위 방법으로 다시 ‘기본값으로 설정’을 누르면 돼요.
