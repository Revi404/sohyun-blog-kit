  • 전체 화면을 파일로 바로 저장하려면 Win + PrtSc, 사진 폴더의 ‘스크린샷’에 저장돼요.

‘클립보드’에 저장됐다는 건 Ctrl + V로 바로 붙여 넣을 수 있다는 뜻이에요. 카톡·메일·문서에 바로 붙이면 돼요.

Win + Shift + S 사용법

  1. Win + Shift + S를 누르면 화면이 살짝 어두워지고 위쪽에 작은 메뉴가 나와요.
  2. 사각형 · 자유형 · 창 · 전체 화면 중 하나를 골라요.
  3. 원하는 부분을 마우스로 끌어 선택하면 오른쪽 아래에 알림이 떠요.
  4. 알림을 누르면 캡처 도구가 열려서 펜·형광펜으로 표시하거나 자를 수 있어요 ✅

PrtSc 키 하나로 캡처 도구 열기

최근 윈도우 11에서는 PrtSc 키만 눌러도 캡처 도구가 열리도록 기본 설정이 바뀌었어요. 예전처럼 전체 화면이 클립보드에 바로 복사되길 원하면 설정을 바꿔야 해요.

  1. 설정 > 접근성 > 키보드로 들어가요.
  2. PrtSc 키를 사용하여 화면 캡처 열기 스위치를 켜거나 꺼요.

캡처 도구 오른쪽 위 … → 설정에서 ‘스크린샷 자동 저장’을 켜 두면, 클립보드뿐 아니라 파일로도 항상 남아서 나중에 찾기 쉬워요.

스크롤 화면 전체를 캡처하고 싶다면

긴 웹페이지를 한 장으로 저장하고 싶을 때가 있죠. 윈도우 캡처 도구에는 스크롤 캡처 기능이 없지만, 윈도우 11에 기본으로 들어 있는 엣지 브라우저로 해결할 수 있어요 🙌

  1. 엣지에서 캡처할 페이지를 열어요.
  2. Ctrl + Shift + S를 눌러 웹 캡처를 실행해요.
  3. 전체 페이지 캡처를 선택하면 아래까지 한 장으로 저장돼요.
  4. 오른쪽 위 저장 아이콘을 누르면 다운로드 폴더에 이미지 파일로 저장돼요.

크롬을 쓰고 있다면 같은 주소를 엣지에 붙여 넣어 열면 돼요. 로그인이 필요한 페이지는 엣지에서도 로그인해야 내용이 보여요.

캡처한 이미지에 개인정보가 있다면

오류 화면을 남에게 보낼 때 이메일 주소, 전화번호, 계좌번호가 같이 찍히는 경우가 많아요. 캡처 도구에서 형광펜으로 덧칠하면 아래 글자가 비쳐 보일 수 있으니, 펜 도구를 굵게 설정해서 완전히 가리거나 그 부분을 잘라내고 보내는 게 안전해요.

스크린샷 폴더 위치 바꾸기

Win + PrtSc로 찍은 파일은 기본적으로 사진 > 스크린샷 폴더에 쌓여요. 바탕화면이나 다른 드라이브에 바로 저장하고 싶다면 파일 탐색기에서 스크린샷 폴더를 오른쪽 클릭 → 속성 > 위치 탭 → 이동으로 원하는 폴더를 지정하면 돼요. 원래대로 돌리고 싶을 땐 같은 탭의 기본값 복원을 누르면 돼요.

자주 묻는 질문

노트북에 PrtSc 키가 안 보여요

일부 노트북은 Fn 키와 함께 눌러야 해요. 키 위에 작게 ‘PrtSc’, ‘PrtScn’, ‘Print’라고 적힌 키를 찾아 Fn + 그 키를 눌러 보세요.

캡처했는데 저장된 파일이 없어요

Win + Shift + S와 Alt + PrtSc는 기본적으로 클립보드에만 저장돼요. 파일이 필요하면 알림을 눌러 캡처 도구에서 저장하거나, Win + PrtSc를 쓰세요.
