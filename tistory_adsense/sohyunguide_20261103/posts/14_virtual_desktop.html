세줄요약
  • 윈도우 11 가상 데스크톱은 Win + Ctrl + D로 새로 만들고, Win + Ctrl + ←/→로 오가요.
  • 업무용·개인용처럼 화면을 나눠 두면 창이 뒤섞이지 않아 집중하기 좋아요.
  • 데스크톱마다 이름과 배경화면을 따로 정할 수 있어서 지금 어느 화면인지 바로 알 수 있어요.
확인 환경 2026-11-03윈도우 11 홈·프로단축키 · 작업 보기

모니터는 하나인데 열어 둔 창은 열 개가 넘어서, 원하는 창을 찾느라 Alt + Tab을 몇 번씩 누르고 계신가요? 🙃 윈도우 11의 가상 데스크톱을 쓰면 화면 하나를 여러 개처럼 나눠 쓸 수 있어요. 업무용 화면, 개인용 화면, 자료 조사용 화면을 따로 두고 단축키로 넘나드는 방식이에요.

가상 데스크톱 만들고 이동하기

하고 싶은 것단축키
새 데스크톱 만들기Win + Ctrl + D
왼쪽·오른쪽 데스크톱으로 이동Win + Ctrl + ← / →
지금 데스크톱 닫기Win + Ctrl + F4
모든 데스크톱 한눈에 보기Win + Tab

데스크톱을 닫아도 그 안에 열려 있던 창은 꺼지지 않고 옆 데스크톱으로 옮겨져요. 작업하던 내용이 사라질 걱정은 하지 않아도 돼요.

노트북 터치패드에서는 네 손가락으로 좌우로 밀기를 하면 데스크톱 사이를 오갈 수 있어요. 터치패드 제스처 설정에 따라 다를 수 있어요.

마우스로 만들고 관리하기

  1. 작업 표시줄의 작업 보기 버튼(사각형 두 개가 겹친 모양)에 마우스를 올려요.
  2. 위로 올라온 목록에서 새 데스크톱(+)을 눌러요.
  3. 데스크톱 이름을 누르면 ‘업무’, ‘개인’처럼 이름을 바꿀 수 있어요.
  4. 데스크톱 미리보기를 오른쪽 클릭하면 배경 선택으로 배경화면도 따로 정할 수 있어요 ✅

작업 보기 버튼이 안 보인다면 설정 > 개인 설정 > 작업 표시줄 > 작업 표시줄 항목에서 ‘작업 보기’를 켜 주세요.

창을 다른 데스크톱으로 옮기기

  1. Win + Tab으로 작업 보기 화면을 열어요.
  2. 옮길 창의 미리보기를 위쪽(또는 아래쪽) 데스크톱 목록으로 끌어다 놓아요.
  3. 또는 창 미리보기를 오른쪽 클릭 → 이동 위치에서 데스크톱을 골라요.

같은 메뉴의 모든 데스크톱에 이 창 표시를 고르면 메신저처럼 어느 화면에서든 보여야 하는 창을 항상 띄워 둘 수 있어요.

이렇게 나눠 쓰면 편해요

데스크톱띄워 둘 창배경 예시
1. 업무메일, 업무 문서, 사내 메신저단색 배경
2. 자료 조사브라우저 여러 창, 메모장밝은 풍경
3. 개인음악, 쇼핑, 개인 메신저좋아하는 사진

화상회의로 화면을 공유할 때도 업무 데스크톱만 보여 주면 개인 창이 실수로 노출될 일이 줄어들어요. 데스크톱 수는 처음엔 2~3개로 시작하는 게 관리하기 쉬워요.

실제로 써 보면 이런 점이 좋아요

가상 데스크톱의 가장 큰 장점은 머릿속 전환 비용이 줄어든다는 거예요 🧠 업무 창과 개인 창이 한 화면에 섞여 있으면, 보고서를 쓰다가도 작업 표시줄에 뜬 쇼핑몰 탭이나 개인 메신저 알림에 시선이 가기 쉬워요. 데스크톱을 나눠 두면 지금 화면에는 지금 할 일과 관련된 창만 남아서 집중이 훨씬 오래 가요.

프로젝트를 여러 개 동시에 진행하는 분들에게도 유용해요. 데스크톱 이름을 ‘A 거래처’, ‘B 거래처’처럼 지어 두고 각 프로젝트의 문서·폴더·브라우저 창을 따로 열어 두면, 오전에는 A, 오후에는 B 식으로 전환할 때 창을 다시 찾을 필요가 없어요. 하루 업무를 마칠 땐 다 쓴 데스크톱만 Win + Ctrl + F4로 닫으면 되고요.

반대로 창이 몇 개 안 되는 분이라면 데스크톱을 나누는 게 오히려 번거로울 수 있어요. 열린 창이 대여섯 개를 넘기 시작할 때 시도해 보는 걸 추천해요.

작업 표시줄에 어떤 창이 보일지 정하기

기본 설정에서는 작업 표시줄에 지금 데스크톱의 창만 표시돼요. 다른 데스크톱의 창까지 모두 보고 싶다면 설정 > 시스템 > 멀티태스킹 > 데스크톱에서 ‘작업 표시줄에 열려 있는 모든 창 표시’를 모든 데스크톱에서로 바꾸면 돼요. 같은 화면에서 Alt + Tab에 보이는 창 범위도 함께 정할 수 있어요.

자주 묻는 질문

PC를 껐다 켜면 데스크톱이 사라지나요?

데스크톱 자체와 이름·배경은 남아 있어요. 다만 그 안에 열려 있던 프로그램은 다시 실행해야 해요.

모니터 두 대에서도 쓸 수 있나요?

네, 데스크톱을 전환하면 두 모니터가 함께 바뀌어요. 모니터마다 따로 전환되지는 않아요.
