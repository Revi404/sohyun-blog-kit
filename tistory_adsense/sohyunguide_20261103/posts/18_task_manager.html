세줄요약
  • 윈도우 11 작업 관리자는 Ctrl + Shift + Esc 한 번으로 바로 열려요.
  • ‘응답 없음’ 프로그램은 프로세스 탭에서 선택한 뒤 작업 끝내기를 누르면 강제로 종료돼요.
  • PC가 느릴 땐 CPU·메모리 열을 눌러 정렬하면 무엇이 자원을 많이 쓰는지 바로 보여요.
확인 환경 2026-11-03윈도우 11 홈·프로작업 관리자

프로그램 창이 하얗게 변하면서 제목에 ‘(응답 없음)’이 붙고, X 버튼을 눌러도 꺼지지 않을 때가 있죠 😵 이럴 때 전원 버튼부터 누르면 다른 작업까지 같이 날아가요. 작업 관리자로 멈춘 프로그램만 골라서 끄는 방법을 알아 두면 훨씬 안전하게 해결할 수 있어요.

작업 관리자 여는 방법

방법하는 법
단축키 (가장 빠름)Ctrl + Shift + Esc
보안 화면에서Ctrl + Alt + Delete → 작업 관리자
시작 버튼 메뉴시작 버튼 오른쪽 클릭 → 작업 관리자
작업 표시줄작업 표시줄 빈 곳 오른쪽 클릭 → 작업 관리자
화면 전체가 멈춘 것 같을 때는 Ctrl + Alt + Delete가 가장 잘 먹혀요. 이 화면은 윈도우가 따로 띄우는 보안 화면이라, 다른 프로그램이 멈춰 있어도 대부분 열려요.

응답 없는 프로그램 끄기

  1. 작업 관리자를 열고 왼쪽 메뉴에서 프로세스를 선택해요.
  2. 앱 목록에서 멈춘 프로그램을 찾아요. 상태 칸에 ‘응답 없음’이 표시되는 경우가 많아요.
  3. 프로그램을 선택하고 위쪽의 작업 끝내기를 눌러요 ✅
강제로 끈 프로그램에서 저장하지 않은 내용은 사라질 수 있어요. 워드·한글·엑셀처럼 자동 저장 기능이 있는 프로그램은 다시 열었을 때 복구 파일을 보여 주는 경우가 있으니 꼭 확인해 보세요.

PC가 느릴 때 원인 찾기

프로세스 화면 위쪽의 CPU · 메모리 · 디스크 · 네트워크 열 이름을 누르면 많이 쓰는 순서대로 정렬돼요. 맨 위에 올라온 프로그램이 지금 PC를 가장 바쁘게 만드는 주인공이에요.

열높을 때 흔한 원인해 볼 것
CPU영상 인코딩, 백신 검사, 멈춘 프로그램필요 없는 프로그램 종료
메모리브라우저 탭 수십 개, 대용량 파일안 쓰는 탭 닫기
디스크업데이트 설치, 동기화, 검색 색인잠시 기다리기
네트워크업데이트·클라우드 동기화·다운로드다운로드 일시 중지

이름이 낯선 항목이라도 무작정 끄지는 마세요. ‘Windows 프로세스’ 그룹에 있는 항목은 윈도우가 동작하는 데 필요한 경우가 많아서, 끄면 화면이 깜빡이거나 PC가 다시 시작될 수 있어요. 모르는 항목은 오른쪽 클릭 → 온라인 검색으로 정체를 먼저 확인해 보세요.

작업 표시줄·바탕화면이 멈췄을 때

프로그램이 아니라 작업 표시줄이나 시작 메뉴가 반응하지 않을 때는 Windows 탐색기를 다시 시작하면 돼요. 프로세스 목록에서 Windows 탐색기를 선택하고 위쪽 작업 다시 시작을 누르면, 화면이 잠깐 깜빡인 뒤 작업 표시줄이 새로 뜨면서 대부분 정상으로 돌아와요. 열려 있던 다른 프로그램은 그대로 유지돼요.

성능 탭으로 PC 상태 한눈에 보기

왼쪽 메뉴의 성능을 누르면 CPU, 메모리, 디스크, 와이파이, GPU 사용량이 실시간 그래프로 나와요 📈 특히 메모리 항목에서 ‘사용 중’ 수치가 전체 용량에 거의 닿아 있는 상태가 자주 보인다면, 프로그램을 덜 띄우거나 메모리 증설을 고민해 볼 만해요. 반대로 그래프가 늘 낮은데도 PC가 느리다면 저장 장치나 다른 원인일 가능성이 높아요.

또 CPU 화면 오른쪽 아래에는 작동 시간이 표시돼요. 며칠째 PC를 껐다 켜지 않았다면 여기 숫자가 아주 크게 나오는데, 이럴 땐 한 번 다시 시작하는 것만으로도 체감 속도가 좋아지는 경우가 많아요.

시작 프로그램 탭도 같이 활용하기

왼쪽 메뉴의 시작 앱에서는 PC를 켤 때 자동으로 실행되는 프로그램 목록과 시작 영향(높음·보통·낮음)을 볼 수 있어요. 영향이 ‘높음’인데 매번 쓰지 않는 프로그램은 선택 후 사용 안 함을 누르면 부팅이 가벼워져요.

자주 묻는 질문

작업 끝내기를 눌러도 안 꺼져요

프로그램이 여러 개의 하위 작업으로 나뉘어 있는 경우예요. 왼쪽 메뉴의 세부 정보에서 같은 이름의 항목을 찾아 오른쪽 클릭 → 프로세스 트리 끝내기를 해 보세요.
