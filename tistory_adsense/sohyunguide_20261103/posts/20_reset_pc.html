이 PC 초기화 진행 순서

  1. Win + I → 시스템 > 복구로 들어가요.
  2. 이 PC 초기화 옆 PC 초기화 버튼을 눌러요.
  3. 내 파일 유지 또는 모든 항목 제거 중 하나를 골라요.
  4. 윈도우를 다시 설치할 방법으로 클라우드 다운로드 또는 로컬 다시 설치를 골라요.
  5. 설정 내용을 확인하고 초기화를 누르면 PC가 여러 번 다시 시작되며 진행돼요 ✅

초기화하기 전에 먼저 해 볼 것

초기화는 프로그램을 전부 다시 설치해야 해서 시간이 꽤 들어요. 오류 해결이 목적이라면 아래 방법을 먼저 해 보고, 그래도 안 될 때 초기화하는 순서를 추천해요.

방법위치효과
최근 업데이트 제거Windows 업데이트 > 업데이트 기록 > 업데이트 제거업데이트 직후 생긴 문제
문제를 일으킨 앱 제거앱 > 설치된 앱특정 프로그램 설치 후 생긴 문제
시작 앱 정리작업 관리자 > 시작 앱부팅이 느린 문제
Windows 업데이트로 문제 해결시스템 > 복구앱·설정은 두고 윈도우만 다시 설치

마지막 항목은 최근 윈도우 11에 추가된 기능으로, 버전에 따라 복구 화면에 보이지 않을 수 있어요.

PC를 팔거나 물려줄 때

모든 항목 제거를 고르면 다음 화면에 설정 변경이 있어요. 여기서 데이터 정리(드라이브 정리)를 켜면 지운 파일을 복구 프로그램으로 되살리기 어렵게 덮어써 줘요. 시간이 몇 시간 더 걸리지만, 남에게 넘길 PC라면 꼭 켜는 걸 추천해요. 초기화가 끝나면 처음 설정 화면에서 멈추고 PC를 끈 뒤 넘기면, 새 주인이 자기 계정으로 설정할 수 있어요.

자주 묻는 질문

초기화에 시간이 얼마나 걸리나요?

PC 사양과 선택한 방식에 따라 크게 달라요. 데이터 정리를 켜면 훨씬 오래 걸리니, 저녁에 시작해서 충분한 시간을 두는 게 좋아요.

윈도우 정품 인증은 다시 해야 하나요?

같은 PC에서 초기화하면 보통 인터넷에 연결된 뒤 자동으로 인증돼요. 인증 상태는 설정 > 시스템 > 정품 인증에서 확인할 수 있어요.

초기화 도중에 멈춘 것 같아요

진행률이 한참 그대로여도 내부에서는 작업이 계속되고 있는 경우가 많아요. 전원을 강제로 끄면 부팅이 안 될 수 있으니 충분히 기다려 주세요.
