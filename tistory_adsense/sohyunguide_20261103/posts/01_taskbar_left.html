윈도우 11로 바꾸고 나서 제일 먼저 어색한 게 가운데로 몰린 시작 버튼이죠 😅 손이 습관처럼 왼쪽 아래로 가는데 아무것도 안 눌려서 당황한 적, 한 번쯤 있으실 거예요. 다행히 설정 한 줄만 바꾸면 예전처럼 왼쪽 정렬로 돌아가요!

작업 표시줄 왼쪽 정렬하는 방법

  1. 작업 표시줄의 빈 곳을 마우스 오른쪽 버튼으로 눌러요.
  2. 작업 표시줄 설정을 선택해요.
  3. 아래로 내려 작업 표시줄 동작을 펼쳐요.
  4. 작업 표시줄 맞춤을 가운데에서 왼쪽으로 바꾸면 끝이에요 ✅

바꾸는 즉시 아이콘이 왼쪽으로 미끄러지듯 이동해요. 재부팅이나 로그아웃은 필요 없어요.

설정 앱을 직접 여는 단축키는 Win + I예요. 개인 설정 > 작업 표시줄로 들어가도 같은 화면이 나와요.

같이 정리하면 좋은 작업 표시줄 항목

왼쪽 정렬을 하러 들어간 김에 안 쓰는 버튼도 정리해 두면 작업 표시줄이 훨씬 깔끔해져요 🙂 작업 표시줄 항목 메뉴에서 바로 바꿀 수 있어요.

항목선택지추천
검색숨기기 / 검색 아이콘만 / 검색 아이콘 및 레이블 / 검색 상자공간이 좁으면 ‘검색 아이콘만’
작업 보기켬 / 끔가상 데스크톱을 안 쓰면 끔
위젯켬 / 끔날씨·뉴스를 안 보면 끔

검색 버튼을 숨겨도 검색 기능은 그대로예요. Win 키를 누르고 바로 글자를 입력하면 시작 메뉴에서 검색돼요.

작업 표시줄을 화면 위나 옆으로 옮길 수 있나요?

윈도우 10에서는 작업 표시줄을 끌어서 화면 위·왼쪽·오른쪽에 붙일 수 있었지만, 윈도우 11 기본 설정에는 위치를 옮기는 메뉴가 없어요. 화면 아래 고정이 기본이고, 정렬(가운데·왼쪽)만 고를 수 있어요.

인터넷에 돌아다니는 레지스트리 수정 방법으로 위치를 바꾸는 경우도 있지만, 업데이트 후 다시 초기화되거나 표시가 깨질 수 있어요. 일반 사용자라면 기본 설정 안에서 바꾸는 걸 추천해요.

작업 표시줄 자동 숨기기

노트북처럼 화면이 작다면 작업 표시줄을 평소엔 숨겨 두는 것도 방법이에요. 작업 표시줄 동작 > 작업 표시줄 자동 숨기기에 체크하면, 마우스를 화면 맨 아래로 가져갈 때만 작업 표시줄이 올라와요.

자주 쓰는 앱을 작업 표시줄에 고정하기

정렬을 바꿨다면 이제 아이콘 순서도 내 손에 맞게 정리해 볼 차례예요. 작업 표시줄에 고정해 둔 앱은 Win + 숫자 키로 바로 열 수 있어서, 순서를 잘 잡아 두면 마우스 없이도 빠르게 움직일 수 있어요 ⚡

  1. 시작 메뉴에서 자주 쓰는 앱을 찾아 마우스 오른쪽 버튼을 눌러요.
  2. 작업 표시줄에 고정을 선택해요.
  3. 고정된 아이콘을 마우스로 끌어서 원하는 순서로 옮겨요.
  4. 왼쪽에서 첫 번째 앱은 Win + 1, 두 번째 앱은 Win + 2로 열려요.

예를 들어 첫 번째에 파일 탐색기, 두 번째에 크롬, 세 번째에 카카오톡을 두면 Win + 1 · 2 · 3만으로 하루 업무 대부분을 시작할 수 있어요. 고정을 풀고 싶을 땐 아이콘을 오른쪽 클릭해서 작업 표시줄에서 제거를 누르면 돼요.

오른쪽 아래 아이콘(시스템 트레이) 정리

시계 옆 작은 아이콘들도 같은 설정 화면에서 정리할 수 있어요. 기타 시스템 트레이 아이콘을 펼치면 앱별 스위치가 나오는데, 켠 앱은 항상 보이고 끈 앱은 위쪽 화살표(^) 안으로 숨어요. 메신저나 클라우드 동기화처럼 상태를 자주 확인하는 앱만 켜 두면 시계 주변이 한결 깔끔해져요.

자주 묻는 질문

왼쪽 정렬로 바꿨는데 시작 메뉴 모양은 그대로예요

맞아요. 정렬 설정은 위치만 바꿔요. 시작 메뉴 디자인은 윈도우 11 형태 그대로 유지되고, 열리는 위치만 왼쪽 아래로 바뀌어요.

다시 가운데로 돌리고 싶어요

같은 메뉴에서 작업 표시줄 맞춤을 ‘가운데’로 바꾸면 바로 원래대로 돌아가요.

설정 메뉴에 ‘작업 표시줄 맞춤’이 안 보여요

회사·학교에서 관리하는 PC는 관리자가 설정을 막아 둔 경우가 있어요. 개인 PC인데도 안 보인다면 설정 > Windows 업데이트에서 최신 업데이트를 먼저 설치해 보세요.
