# 소현생정 캐릭터 스티커

| 폴더·파일 | 용도 |
|---|---|
| `stickers/catalog.json` | **기준 목록.** 스티커마다 id, 종류(full 전신 / mini 얼굴 / icon 아이콘), 표정 설명, 감정 그룹(emotions), 쓰임새, 파일 경로 |
| `stickers/<id>.png` | 블로그용(원본 절반 크기, 가로 106~140px). 전신(full)만 있음 |
| `stickers_full/<id>.png` | 원본 크기 투명 누끼. 카드뉴스·티어표·릴스 합성용(전신·미니·아이콘 전부) |

PC 사본: `SNS작업\소현\디자인시스템\캐릭터\` — `스티커_블로그용\`(= stickers/), `스티커_누끼\`(= stickers_full/), `감정별_사용가이드.md`

## 스킬에서 고르는 법 (모든 소현 스킬 공통)

1. `catalog.json`을 읽는다. 스킬 본문에 적힌 파일명은 **기본 예시**일 뿐이다.
2. 넣을 자리의 감정(바로 앞 문장·장표 내용)을 `emotion_groups` 중 하나로 정한다.
3. 그 감정을 가진 스티커 중에서 고른다. 블로그 글은 `kind: full`이면서 `blog`가 있는 것만, 카드뉴스·티어표·릴스는 `full`에서 고르고 `mini`·`icon`은 보조 장식으로만 쓴다.
4. 같은 감정 후보가 여럿이면 **최근에 추가된 것(added)과 최근 글·영상에서 안 쓴 것**을 우선한다. 한 콘텐츠 안에서 같은 스티커를 두 번 쓰지 않는다.
5. 원격 주소: `https://raw.githubusercontent.com/Revi404/sohyun-blog-kit/main/<blog 또는 full 경로>`

## 새 스티커 등록 (사용자가 "스티커 추가했어" 또는 새 파일을 줄 때)

1. 새 PNG를 PC `SNS작업\소현\디자인시스템\캐릭터\새스티커\`에서 가져온다(또는 대화 첨부).
2. 이미지를 직접 보고(Read) 표정을 한 줄로 설명하고 감정 그룹 1~2개, 쓰임새를 정한다. 애매하면 사용자에게 확인한다.
3. 배경이 투명이 아니면 흰 배경을 지운다(테두리 2px 안쪽 흰색 → 투명, 결과를 콘택트시트로 확인).
4. id는 `NN_영문이름`(전신, 이어지는 번호) / `mini_NN_이름` / `icon_이름`으로 정한다.
5. 저장: 원본 크기 → `stickers_full/<id>.png`와 PC `스티커_누끼\`. 전신이면 기존 블로그용과 같은 비율(원본 가로의 절반, LANCZOS)로 줄여 `stickers/<id>.png`와 PC `스티커_블로그용\`.
6. `catalog.json`에 항목을 추가하고(added = 오늘), PC `감정별_사용가이드.md` 표에도 한 줄 추가한다.
7. 저장소에 커밋·푸시한다(이 작업은 사용자와 함께하는 수동 세션에서만. 예약 작업은 저장소에 쓰지 않는다).
8. 등록한 스티커를 콘택트시트로 보여 주고 감정 분류를 사용자에게 확인받는다.

스킬 파일을 고칠 필요는 없다. 모든 스킬이 이 목록을 읽기 때문이다.
